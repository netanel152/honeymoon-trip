**רוב הדברים לא דורשים אותי בכלל.** פותחים את האתר בנייד ועורכים ישירות:

| מה | איפה באתר |
|---|---|
| רישום הוצאה בשטח | טאב **💸 הוצאות**, כפתור "הוצאה חדשה" (או מהסקירה, מתיבת "הוצאות היום") |
| שורה בתקציב — הוספה, עריכה, מחיקה | טאב **💸 הוצאות**, בתוך "הפירוט המלא" |
| תזכורת חדשה / עריכה / מחיקה | טאב **⏰ תזכורות** |
| הערה אישית ליום מסוים | בתחתית כל כרטיס יום ביומן |
| מקום חדש במפות | טאב **📍 כל המקומות**, כפתור ההוספה למעלה |
| פריט לצ׳קליסט / סימון וי | טאב **✅ צ׳קליסט** |

הכול נשמר ומסתנכרן בין נתנאל לעדי אוטומטית (כל 45 שניות, וגם כשחוזרים לאפליקציה).
עובד גם בלי אינטרנט — השינויים נשמרים מקומית ונדחפים כשחוזרת קליטה.

בכל מקום שיש בו "שחזור לרשימה המקורית" — הוא מוחק רק את מה שאתם הוספתם או ערכתם,
ולא נוגע בשאר האתר.

## כשיוצאת גרסה חדשה

אחרי שינוי באתר יופיע למעלה באנר **"✨ יש גרסה חדשה של האתר"**. לחיצה אחת על "רענון"
ומקבלים את הגרסה החדשה. אין צורך לרענן פעמיים.

## אם צריך שינוי במבנה עצמו

שכתוב של יום ביומן, טבלת רכבת חדשה, טאב חדש — זה כן דורש עריכת קוד.
פותחים את **קלוד באפליקציה**, בוחרים את הריפו הזה, ומבקשים את השינוי.
כל דחיפה ל-`main` מפרסמת את האתר אוטומטית תוך כדקה.

## מבנה הפרויקט

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האתר — קובץ אחד. עמוד עברי RTL, בלי צינור בנייה. |
| `sw.js` | Service Worker — שימוש אופליין ובאנר העדכון. |
| `manifest.webmanifest` + האייקונים | התקנה כאפליקציה במסך הבית. |
| `build.mjs` | מעתיק את קבצי המקור אל `dist/` (תיקיית הפרסום) וחותם את גרסת ה-Service Worker לפי תוכן העמוד. |
| `netlify.toml` | הגדרות הפריסה האוטומטית. |
| `deploy.mjs` | פריסה ידנית מהמחשב דרך ה-API. לא נחוצה כשיש פריסה אוטומטית. |
| `netlify/functions/trip.js` | האחסון המשותף — Netlify Blobs, מיזוג לפי חותמת זמן לכל פריט. |
| `CLAUDE.md` | כל ההקשר וההיסטוריה של הפרויקט. **לקרוא לפני שינוי משמעותי.** |
| `טיול ירח דבש.docx` | מסמך המקור של המסלול. |
| `הוצאות ירח דבש.xlsx` | גיליון ההוצאות. |
| `csv-source/` | רשימות המקומות השמורות מגוגל מפות (ייצוא Takeout). |

**חשוב:** רק `dist/` מתפרסמת לאינטרנט. ה-Word, האקסל וה-PDF-ים נשארים בריפו הפרטי
ולא נגישים מהרשת. `dist/` עצמה היא תוצר בנייה ולא נשמרת בגיט.

## פריסה

אוטומטית בכל דחיפה ל-`main` — Netlify מריץ `node build.mjs` ומפרסם את `dist/`.
פריסה ידנית מהמחשב: `node deploy.mjs` (דורשת `.netlify-token.txt`, שלא נמצא בריפו).
